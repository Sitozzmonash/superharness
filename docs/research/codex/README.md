# Codex Research Notes

Every major Super Harness runtime feature must have a research note in this directory before its
implementation begins. Each note must identify the files and tests inspected at the commit recorded
in [`references/CODEX_PIN.md`](../../../references/CODEX_PIN.md), extract behavioral contracts and
invariants, remove OpenAI-specific coupling, and describe the Python-native design and tests.

Phase 0 establishes the pinned source. Feature-specific research starts with Phase 1.
